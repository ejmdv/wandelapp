# Wandelapp

- **Oefenapp** (Kompas Oefentocht): https://ejmdv.github.io/wandelapp/oefen/ — korte opdrachten bij de punten van een kompaswandeling met papieren kaart, aankomstcontrole en voortgang zonder bereik. Werkt offline na de eerste keer openen.
- **Noodpagina**: https://ejmdv.github.io/wandelapp/nood/ — hints naar het volgende doel als je vastloopt. De route zit alleen in de #-hash van de link en gaat niet naar een server.

Beide worden gemaakt met de planner (niet in deze repository). Publiceren: `tools/publiceer_oefen.sh` en `tools/publiceer_nood.sh` in de projectmap.
